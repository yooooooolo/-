# 玄龟卜易 · 六爻纳甲在线占卜

> 基于京房纳甲法的周易六爻占卜工具 | 纯前端 | 汉墓龟甲风格

## 🪙 功能

- 模拟三枚硬币摇卦（随机生成六爻）
- 自动计算本卦、变卦、六亲、世应、六神（严格按京房纳甲法）
- 根据卦象、动爻、世应、用户所问之事动态生成解读
- 支持手机/电脑自适应，可添加到主屏幕像 App 一样使用

## 🎨 特色

- 汉墓龟甲 + 盘龙纹 + 回纹边框的复古界面
- 摇卦动画（“龟甲渐裂”沉浸感）
- 完全前端运行，无需后端，数据隐私安全

## 🛠 技术栈

- HTML5 + CSS3 + JavaScript（原生）
- 无外部依赖，单文件即用

## 📦 部署

本仓库为静态网页，可直接部署到：
- GitHub Pages
- Cloudflare Pages
- Netlify

## 📄 使用说明

1. 在输入框中写下您要问的事（例如：“周三面试结果如何？”）
2. 点击“灼龟摇卦”按钮
3. 等待动画结束，查看卦象和解读
